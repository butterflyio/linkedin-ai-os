# LinkedIn AI OS

Every file below is read before any post is drafted. Read them in this order.

## Brand files (the context)

- brands/you/voice.md - how I write. Non-negotiable. Including no em dashes.
- brands/you/about-me.md - who I am, what I believe, what I avoid.
- brands/you/audience.md - who reads. Draft for this reader.
- brands/you/story-bank.md - real stories. Never invent one.

## Skills

- skills/post-writer/SKILL.md - draft a post in my voice.
- skills/hook-generator/SKILL.md - 6 opening hooks.
- skills/post-scorer/SKILL.md - score a draft before posting.

## Tool

- tools/caption_gate.py - programmatic pre-publish gate.

## Workflow for a new post

1. Idea comes from a real story, project, or Web3 x AI observation.
2. Read the brand files above.
3. hook-generator -> pick the strongest hook.
4. post-writer -> full draft in voice.
5. post-scorer + caption_gate.py -> PASS before anything ships.
6. I approve. Nothing is auto-published.
